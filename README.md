# 条款引用校验台

本地运行的中文法规条款编号与交叉引用校验工具。粘贴含「第 X 条 / 款 / 项」编号与交叉引用的条款文本，系统自动解析为可折叠的 **条 → 款 → 项** 层级文档，在正文与关系视图之间联动高亮引用，实时检测断链、自引用与循环引用，并在拖拽调整条款顺序后**原子更新**所有可唯一定位的引用；还可把任意时刻的文档保存为**命名快照**，在「版本对比」视图按稳定节点 ID 比较两个版本的节点增删改、移动与引用差异。

- 纯本地运行，数据保存在浏览器 `localStorage` 与本机文件，无需任何外部账号或网络服务。
- 技术栈：React 18 + TypeScript（Vite）+ Node.js / Express。

## 一条命令启动（推荐 Docker）

需要 Docker 与 Docker Compose（v2）。

```bash
docker compose up --build
```

启动后浏览器访问：

> **http://localhost:3000**

数据持久化在命名卷 `clause-data`（容器内 `/data/state.json`）。停止与清理：

```bash
docker compose down            # 停止（保留数据）
docker compose down -v         # 停止并删除数据卷
```

若要改用目录挂载而非命名卷，可在 `docker-compose.yml` 中把 `clause-data:/data` 改为 `./data:/data`。

## 不用 Docker，直接用 Node 运行

要求 Node.js 20+。

```bash
npm install
npm run build
npm start
```

同样访问 http://localhost:3000 。

开发模式（前端热更新 + 后端自动重启，前端在 5173，API 代理到 3000）：

```bash
npm run dev
```

健康检查：`curl http://localhost:3000/api/health`

## 功能说明

### 1. 粘贴解析
- 点击右上角「粘贴 / 导入」，把条款文本贴入即可。
- 识别规则：
  - `第一条`、`第 12 条`、`第十条之一` 开头的行作为**条**，行内 `【标题】` 作为条标题；
  - 条下的自然段落为**款**；`（一）`、`(一)`、`【一】`、`一、`、`1.` 等形式识别为**项**；
  - 数字支持中文（一、十、二十三、一百零五）、阿拉伯与全角数字；
  - 编号保留原文（支持跳号与「之一/之二」后缀条），款、项按结构位置编号。
- 也可在弹窗中选择之前导出的 JSON 文件恢复数据，或载入内置示例。

### 2. 可折叠层级与正文编辑
- 条可折叠；点击条号（如「第五条」）可直接输入新编号，与目标位置的条交换顺序。
- 点击任意正文即可就地编辑，`Ctrl+Enter` 保存、`Esc` 取消；编辑过程中的连续输入在撤销时合并为一次。
- 条标题栏左侧的 ⠿ 手柄可**拖拽排序**；支持 `+款 / +项 / +条` 新增与删除。

### 3. 引用解析与联动高亮
正文内可识别的引用形式包括：

| 类型 | 示例 |
| --- | --- |
| 绝对引用 | `第五条`、`第十二条之一`、`第五条第二款`、`第五条第二款第（一）项` |
| 本条 | `本条第三款`、`本条第二款第（二）项` |
| 相邻条 | `前条`、`上条`、`后条`、`下条` |
| 款 / 项相对引用 | `前款第（二）项`、`前项`、`本款第（一）项`、`本项`、`（三）` |

- 有效引用为绿色，断链红色波浪下划线，自引用黄色，歧义引用蓝色。
- **悬停**正文里的引用：引用本身高亮，目标条款卡片发光。
- **点击**有效引用：滚动并定位到目标节点。
- 右侧「关系视图」以环形图展示条级引用边：悬停/点击边与正文双向联动，自引用为黄色自环、处于循环中的边与节点标紫、含断链的条标红。

### 4. 结构调整后的原子改写
- 拖拽排序、点击条号改编号、新增/删除节点后，系统对照调整前的解析结果：
  - 对所有**可唯一定位**的绝对引用一次性、按字符偏移原子改写（如第三条移到末尾，「第三条」自动变为「第五条」），保留原文数字风格（中文/阿拉伯）与「（X）」括号写法及条名；
  - 相对引用（本条、前款、前项、后条……）**不改写**，由结构位置自动跟随；
  - 操作结束后弹出提示，告知自动改写数量与未处理数量。
- 整个结构操作与改写是一次提交，可整体「撤销 / 重做」（按钮或 `Ctrl+Z` / `Ctrl+Y`，`Ctrl+Shift+Z`）。

### 5. 不可唯一定位的引用：只列候选，绝不自动改写
以下情况标记为**歧义**，不会被自动改写，而是在右侧问题面板列出全部候选，由用户单选确认：

- 存在同序号条（如同时有「第八条」与「第八条之一」时，单独写「第八条」）；
- 只给项号、未给款号，且同一条多款下都有该序号项。

确认后该引用按所选目标解析并参与后续结构改写；确认记录会保留在问题列表中（标记「已确认」），可随时跳转目标或撤销确认。

### 6. 问题检测与跳转
右侧「问题与引用」实时统计并分类：

- **断链**：目标条/款/项不存在，或相对引用越过边界（如第一条引用「前款」）；
- **自引用**：引用解析到其所在节点自身（如项内写「本项」自指）；
- **循环引用**：条级有向图上的环（如第六条 ↔ 第七条互相援引），列出完整环路；
- **歧义引用**：见上节。

点击问题中的源句可跳到正文对应句子并高亮；点击目标/环路节点可跳到对应条款。

### 7. 撤销 / 重做 与 JSON 导入导出
- 顶部「↶ 撤销 / ↷ 重做」，历史最多保留 100 步；连续文本输入自动合并。
- 「导出 JSON」下载完整文档、歧义确认记录与命名快照；「粘贴 / 导入」中可选择 JSON 文件恢复。导出文件形如：

```json
{
  "app": "clause-reference-validator",
  "version": 1,
  "document": { "id": "...", "title": "...", "root": [ /* 条款树 */ ] },
  "confirmed": { "<引用签名>": "<目标节点id>" },
  "snapshots": [
    { "id": "...", "name": "一审稿", "createdAt": 1789000000000, "doc": { /* 保存时刻的完整文档 */ }, "confirmed": {} }
  ],
  "exportedAt": "2026-09-17T00:00:00.000Z"
}
```

### 8. 版本对比（命名快照）

入口：顶部工具栏的「**版本对比**」标签（「正文编辑」标签可随时切回）。

- 在版本对比页顶部输入名称（如「一审稿」），点击「**📸 保存当前为快照**」，即可把**当前文档**冻结为只读命名快照。继续编辑后再保存一个版本，就能选择任意两个快照进行比较。
- 节点以**稳定节点 ID** 对齐条、款、项，分别标出：
  - **新增**（绿色）、**删除**（红色）、**正文修改**（黄色，行内以逐字增删高亮）、**位置移动**（紫色，显示「旧位置 → 新位置」）；
  - 同一节点同时发生移动与正文修改时，**两类标记同时保留**。
- 「引用」标签页按**源节点 ID + 引用原文 + 同文序次**（同一节点内同原文第几次出现）对齐引用，列出：
  - **新增引用**、**移除引用**、**目标变化**（原文不变但解析到的目标节点不同，含旧目标 → 新目标）；
  - 每条差异都可点「**→ 跳到当前版本**」回到正文对应节点（该节点已在当前版本删除时不显示跳转）。
- 可勾选「仅显示有变化的节点」折叠未变化部分。
- 快照**只读**：保存后不再随后续编辑变化；删除快照**不影响正文、确认记录与撤销历史**。快照随 JSON 一并导出/导入；旧版导出文件缺少 `snapshots` 字段时按空列表加载。

## 数据保存在哪里

- 浏览器 `localStorage`（键 `clause-reference-validator:v1`）：编辑时即时保存；
- 后端本地文件：每次变更后约 0.6 秒防抖写入
  - Docker：`/data/state.json`（持久卷）
  - 本机：`~/.clause-reference-validator/state.json`，可用环境变量 `DATA_DIR` 更改；
- 首次打开若浏览器无数据，会尝试读取后端文件（便于换浏览器共享），否则载入内置示例。
- 后端仅监听本地 HTTP，提供 `/api/state`（GET/PUT）、`/api/health`，不连接任何外部服务。

```
├── Dockerfile              # 多阶段构建：Node 构建前端 + 打包后端，运行镜像仅含生产依赖
├── docker-compose.yml      # 单命令启动，3000 端口 + 命名卷持久化
├── index.html
├── package.json
├── vite.config.ts          # 开发服务器 5173，/api 代理 3000
├── tsconfig.json
├── shared/
│   └── model.ts            # 前后端共享的数据模型
├── server/
│   └── index.ts            # Express：本地 JSON 存储 API + 静态托管 SPA
├── src/
│   ├── main.tsx / App.tsx
│   ├── components/         # 工具栏、文档树、引用 chip、问题面板、关系视图、版本对比、导入弹窗
│   └── lib/
│       ├── numeral.ts      # 中文/阿拉伯/全角序数互转
│       ├── parser.ts       # 粘贴文本 → 条款树
│       ├── scanner.ts      # 交叉引用正则扫描
│       ├── analyzer.ts     # 引用定位、断链/自引用/循环/歧义分析
│       ├── rewriter.ts     # 结构变更后的原子引用改写
│       ├── diff.ts         # 版本对比：稳定 ID 节点差异 + 引用差异 + 逐字差异
│       ├── snapshot.ts     # 命名快照：创建（只读冻结）与旧数据规整
│       ├── tree.ts         # 树查找/增删/重排
│       ├── store.ts        # 状态、撤销重做、结构操作、快照、持久化
│       ├── highlighter.ts  # 正文 ↔ 关系图 ↔ 版本对比跳转的联动高亮
│       ├── storage.ts      # localStorage + 服务端文件存储
│       └── sample.ts       # 内置示例（含各类问题）
└── scripts/check.ts        # 解析/分析/改写/版本对比核心逻辑的端到端校验
```

## 自检

核心逻辑（数字解析、引用扫描、层级解析、断链/循环/自引用/歧义、拖拽后原子改写、版本对比的节点/引用/逐字差异、快照只读与旧数据兼容）配有不依赖浏览器的检查脚本：

```bash
npm run check
```

预期输出「通过 65 项，失败 0 项」。
